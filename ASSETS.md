and are original work. `npm run assets:check` verifies that every file under
`client/assets/` is covered by a row here.

## Removed synthwave assets

`client/assets/pixi/pixi.mjs` and the old synthwave font files are still present
while unmigrated renderers load them. They are not part of the new visual
language and are removed at the end of the game migration.
